## GET 抽奖

GET RandomEquipment.php

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|num|query|string| 是 |数量|

> 返回示例

> 200 Response

```json
{
  "code": 1,
  "equipments": [
    {
      "id": 1,
      "name": "基础炮弹",
      "description": "升级可增加伤害数值。",
      "buffid": 5,
      "prefabname": "Bullet_Standard",
      "upgradegold": 10,
      "upgradeatk": 1,
      "attack": 1,
      "range": 3,
      "boomprefabname": "HitBig",
      "UIImageName": "BarrelIconBase",
      "maxLevel": 10,
      "level": 1
    }
  ]
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|


## POST 抽奖后加入用户

POST PlayerEquipmentAdd.php

> Body 请求参数

```yaml
id: "2"
level: "1"
openid: oMZEm7S7qbNT-LmjSDUEW9O48kLU

```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 是 |none|
|» id|body|string| 是 |装备id|
|» level|body|string| 是 |等级|
|» openid|body|string| 是 |用户标识|

> 返回示例

> 200 Response

```json
{
  "code": 1,
  "msg": "更新成功，新数据已添加到 equipment 中"
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|
